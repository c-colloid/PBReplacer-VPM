# 困ったとき

## メインウィンドウ

### アクションバーが赤くなった

再配置中にエラーが起きています。Console に `[PBReplacer]` で始まる詳細が出るので、そちらを確認してください。<br>
処理は Undo グループにまとまっているので、Ctrl+Z か ↶ で再配置前に戻せます。

### アバターをドロップしても受け付けない

受け付けるのは VRCAvatarDescriptor の付いたオブジェクトか、Modular Avatar の MA Merge Armature が付いたオブジェクト（衣装）です。<br>
子オブジェクトをドロップした場合は、親をたどって該当するものを探します。見つからないときは何も起きません。

### 列に何も表示されない

* 対象のコンポーネントが Armature の外にある場合は検索対象になりません。列の ＋ に Hierarchy からオブジェクトをドロップすると、そのカテゴリに追加できます
* カテゴリの表示がオフになっている可能性があります。レールのアイコンをクリックすると表示を切り替えられます（Alt+クリックでそのカテゴリだけ表示）

### 再配置後にコンポーネントの参照が切れた

PhysBone の Collider 参照は再配置時に新しいコンポーネントへ付け替えます。ほかのツールやアニメーションが元のオブジェクトのパスを直接参照している場合は、`AvatarDynamics` 配下の新しいパスに合わせてください。

## PBRemap

### チップに ✖（未解決）や ▾（要選択）が出る

移植先に同じ名前のボーンが無い（✖）か、同じ名前のボーンが複数ある（▾）状態です。<br>
直し方は [PBRemap の「対応先がないボーン」](PBRemap.md#対応先がないボーン) を参照してください。未解決のまま移植すると、その参照だけ移植元を指したまま残ります。

### Hierarchy のバーに「参照切れ」が出る

参照が失われていて、参照情報（マニフェスト）も無い状態です。<br>
移植元のシーンで AvatarDynamics を選択し、Inspector の ↻ で参照情報を取り直してから、あらためて持ち出してください。

### 移植先が見つからないと言われる

AvatarDynamics がアバター/衣装/小物の配下にありません。Hierarchy で移植先の子へ移動するか、Inspector のアクションバー右のノードへ移植先をドロップしてください。<br>
自動検出が正しく動かないときは、詳細設定の「手動指定」で移植元/移植先を指定できます。

### サイズの違うアバターに移植したら radius がおかしい

詳細設定の「スケール」を確認してください。Auto は Hips-Head の距離比で補正します。体格の比が Hips-Head と合わないモデルでは、Manual で世界寸法比を直接入力してください。

### BuildOnly にしたのに編集中のシーンが変わらない

正常です。BuildOnly は編集時には何もせず、NDMF のビルド時（再生時）にだけ非破壊で移植します。今すぐ移植したいときは Inspector の **移植 ▶** を押してください。

## 表示

### 日本語が豆腐（□）になる

UI の日本語表示には [UITK Font Fix](https://github.com/c-colloid/UITKFontFix)（`jp.colloid.uitk-font-fix`）を使用しています。VPM の依存関係になっているので、PBReplacer を VCC / ALCOM から導入すると一緒に入ります。<br>
unitypackage で入れた場合は UITK Font Fix を別途導入するか、同梱の Noto Sans JP が使われます。
