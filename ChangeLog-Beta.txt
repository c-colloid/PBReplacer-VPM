このファイルはβ/RC等のプレリリース版の変更履歴です。
安定版リリース時には ChangeLog.txt に総括を記載します。

[3.0.0-beta.9]（次回リリース）
メインウィンドウ: UI を PBRemap Inspector と同じ語彙で刷新。「[アバター] ──(再配置 n →)── [AvatarDynamics]」の流れ表示を上部に置き、真ん中のピルがそのまま主操作（表示中のカテゴリの未処理件数を表示。全件配置済みなら ✔ に変わる）
メインウィンドウ: 縦書きタブを廃止し、左のレールをカテゴリのアイコンチップ（PhysBone / PhysBone Collider / Constraint / Contact）に変更。枠色と右下バッジで未処理件数を示し、クリックで列の表示切替、Alt+クリックでその列だけ表示
メインウィンドウ: 一覧をカテゴリごとの列に統一（6分割固定の Constraint グリッドを廃止）。行頭の → / ✔ で未処理 / 配置済みを示し、配置済みは列末尾に畳める。行のツールチップに元の階層パス
メインウィンドウ: 列へ Hierarchy のオブジェクトをドロップでコンポーネントを追加（Constraint / Contact は型をメニューで選択）。アバターは左ノードへのドロップまたはクリックのピッカーで指定
メインウィンドウ: 複数カテゴリの一括再配置に対応（表示中のカテゴリをまとめて 1 回の Undo で処理）
メインウィンドウ: 完了通知のオーバーレイと状態文字列のツールバーを廃止。成功時は流れが緑に光り、↶ ボタンで直前の再配置を元に戻せる。エラーは流れが赤くなり Console に詳細
メインウィンドウ: 設定ウィンドウを廃止し ⚙ で行内に開閉。変更は即時保存、保存先（プロジェクト / 個人）を見出しで区別。「Prefabを継承」を実装通り「再配置前に Prefab を完全に Unpack」に改称
共通: 確認ダイアログ（メインウィンドウの再配置、PBRemap の移植）は既定でオフ（どちらも Undo 可能なため。⚙ 詳細設定で従来通り表示可）。再配置ダイアログの文言を「n件を再配置します / 再配置する / やめる」に変更
メインウィンドウ: ウィンドウ最小サイズを 600x400 に変更。「Avater」の誤字、ラベルが全て太字になる USS、⚙ ⋮ がアバター欄に重なる配置を修正
共通: strip / node / apply / chip / icon-button / advanced の USS を PBReplacerCommon.uss に切り出し、PBRemap と共有（PBRemap の見た目は変更なし）
共通: カテゴリアイコンはコンポーネント型のスクリプトアイコンを使用し、無い場合は Unity 内蔵の型（HingeJoint / CapsuleCollider / ParentConstraint / SphereCollider）で代替（SDK 3.10.4 は固有アイコンを持たないため内蔵型が使われる）
テスト: メインウィンドウの EditMode テスト（Tests/Editor、UI 生成・件数・レール切替・再配置と Undo・設定保存）を追加

[3.0.0-beta.8]2026.09.02
PBRemap: 設計を刷新。移植元の参照情報（マニフェスト）を「移植元にいる間」に自動保存し、Inspectorを開かなくてもPrefab化・別シーン/別プロジェクトへの持ち出し後に移植できるように
PBRemap: 着せ替え済みアバター（本体＋MA衣装）を複数Armature（コンテキスト）として扱い、本体/衣装それぞれのボーンへ正しく移植。MAのprefix/suffixを名前解決に反映
PBRemap: 移植先の検出を刷新（VRCアバター＞MA衣装ルート＞Animator＞SkinnedMeshを持つ汎用オブジェクト。空の整理用オブジェクトへの誤ドロップは未検出として候補を提示）
PBRemap: スケール補正をVRC SDKの実装に合わせ「元値×世界寸法比×移植元/移植先ボーンのlossyScale比」に変更。再実行・NDMFビルド時の二重適用を解消
PBRemap: 同名ボーンが複数ある場合は自動確定せず「要選択」として候補を提示。未解決参照は件数と一覧を常に表示
PBRemap: Inspectorにボーン対応テーブル（手動マッピング）、スケールモード（自動/手動/なし）、ドロップ時の動作（自動適用/確認/ビルド時のみ）を追加
PBRemap: AvatarDynamics外のPhysBoneCollider参照・Constraintの対象オブジェクト参照を検出し警告
PBRemap: NDMFパスは移植先に接続済みのPBRemapを処理しない（除去のみ）。未解決はNDMFのエラーレポートに表示
メインウィンドウ: 「他のアバターへ移植」はAvatarDynamics自身にPBRemapを付与するように変更
PBRemap: 「衣装ホーム」に対応。アバター内の MA 衣装配下に置いた AvatarDynamics は衣装を単位として扱い、同じアバター内の衣装 v1→v2 や、別アバターに着せた同衣装へ、アバター本体に手を触れずに移植できる。衣装ボーンは衣装同士の寸法比、アバターボーン参照はアバター同士の寸法比で補正
PBRemap: 衣装 Prefab に AvatarDynamics を同梱して別アバターへ置いた場合、失われたアバターボーン参照を参照情報から復元
PBRemap: Inspector を刷新。「移植元 → 移植先」の流れを1行で示し、真ん中の → ボタンで移植。移植先ノードへ Hierarchy からドロップして移動可能。Console と同じアイコン＋件数のチップで ✔解決/＋自動作成/⚠要選択/✖未解決 を示し、問題のある行だけを表に表示。長文の説明・完了ダイアログを廃止しツールチップへ
PBRemap: Hierarchy の PBRemap 行に状態アイコン（接続済み/移植可/参照切れ/置き場所不明）を表示
PBRemap: SceneView を刷新。オーバーレイを Unity 標準ツールバーと同じアイコンのトグル（線/名前/✔＋▾✖ の件数/対応ツール/閉じる）に、ギズモを「青の輪→緑の点、点線=未作成、琥珀=候補/自動作成、赤✕=未解決」の語彙に統一。マーカーをクリックで Ping/候補確定/ツール起動
PBRemap: EditorTool「PBRemap ボーン対応」を追加。未解決の骨をクリックし、移植先の骨に出る点をクリックするだけで手動対応を決められる（Esc で終了、Undo 可）
PBRemap: AutoOnDrop が「解決できない参照が1件でもあると何もしない」問題を修正。候補が複数ある参照が無ければドロップ時に移植し、対応物が無い参照は残して警告する。保留したときも理由を Console に出す
PBRemap: Project からの Prefab ドロップ・ペースト・複製で現れた PBRemap もドロップとして検知（ObjectChangeEvents）。Hierarchy の親ごと移動した場合も検知
PBRemap: BuildOnly のとき、ドロップ時に Console で案内し、Hierarchy と Inspector に ▶（ビルド時に移植）を表示
PBRemap: BuildOnly で移植先が VRC アバター配下でない場合（単体の衣装・小物・Animator だけのオブジェクト。NDMF はこれらを処理しない）に再生しても何も起きなかった問題を修正。再生開始時に PBRemap が非破壊で移植し、PhysBone/Collider/Contact/Constraint のランタイムを再初期化する。案内文言も置き場所に応じて分岐
