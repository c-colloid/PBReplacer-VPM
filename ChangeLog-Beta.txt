[3.0.0-beta.10]2026.09.05
ライトテーマに対応
日本語表示に UITK Font Fix を使用（VCC で一緒にインストールされます。日本語 / 中国語 / 韓国語の OS では OS のフォントで表示）
メインウィンドウ: 行にマウスを乗せると「Hierarchy で表示」「削除」ボタンを表示
メインウィンドウ: 詳細設定を整理。項目のオン / オフをスイッチに変更し、説明はツールチップへ
メインウィンドウ: 未処理の印を ▶ から ○ に、「元に戻す」のアイコンを Undo の記号に変更
修正: 環境によってメインウィンドウが開けなかった問題
修正: 「前回のアバターを自動で読み込む」をオフにしても、開き直すと前のアバターが表示される問題
README を実際の画面のスクリーンショットで書き直し、PBRemap の「うまくいかないとき」の手順を追加

[3.0.0-beta.9]2026.09.03
メインウィンドウの画面を刷新
 - 上部に「アバター → AvatarDynamics」の流れを表示し、真ん中の「再配置 n」ボタンで実行（n は未処理の件数）
 - 左のアイコンから種類（PhysBone / Collider / Constraint / Contact）ごとの表示を切り替え。数字は未処理の件数
 - 一覧は種類ごとの列。○ 未処理 / ✔ 配置済み。配置済みは列の末尾に畳めます
 - 複数の種類をまとめて再配置し、1 回の Ctrl+Z で戻せます
 - Hierarchy のオブジェクトを列へドロップするとコンポーネントを追加
 - 設定ウィンドウを廃止し、⚙ でウィンドウ内に表示。変更はその場で保存
再配置 / 移植の前の確認ダイアログを既定でオフに変更（⚙ で有効にできます）
ウィンドウの最小サイズを 600×400 に変更

[3.0.0-beta.8]2026.09.02
PBRemap: 移植元の参照情報を自動で保存するようになり、Prefab 化や別シーン / 別プロジェクトへ持ち出した後も移植できます
PBRemap: 着せ替え済みアバター（本体 + MA 衣装）に対応。衣装だけの移植（衣装 v1 → v2、別アバターに着せた同じ衣装）はアバター本体に触れずに行えます
PBRemap: 移植先の検出を改善（VRC アバター / MA 衣装 / Animator / SkinnedMesh を持つ小物）
PBRemap: 同名の骨が複数あるときは自動で決めず「要選択」として候補を表示。未解決の参照は件数と一覧を常に表示
PBRemap: Inspector を刷新。「移植元 → 移植先」の流れと ▶ ボタン、✔ / ＋ / ▾ / ✖ の件数チップ、問題のある行だけの表
PBRemap: SceneView に対応線を表示。赤 ✕ をクリックすると「ボーン対応」ツールで移植先の骨を選べます
PBRemap: Hierarchy に状態アイコンを表示
PBRemap: ドロップ時の動作（自動で移植 / 確認 / ビルド時のみ）とスケール（自動 / 手動 / なし）を設定に追加
PBRemap: スケール補正を VRC SDK の計算に合わせ、再実行や NDMF ビルドで二重に補正されないように修正
PBRemap: BuildOnly で移植先が VRC アバター配下でないとき（単体の衣装 / 小物）に何も起きなかった問題を修正。再生開始時に非破壊で移植します
PBRemap: 自動で移植する設定のとき、解決できない参照が 1 件でもあると何もしなかった問題を修正
PBRemap: Prefab のドロップ / ペースト / 複製で現れた PBRemap も検知

[3.0.0-beta.7]2026.07.21
メインウィンドウ: 右クリックの削除に確認ダイアログを追加（Ctrl+Z で戻せます）
メインウィンドウ: 右上の ⋮ メニューと GameObject メニューから PBRemap を追加できます
設定: 保存先を個人設定（EditorPrefs）とプロジェクト設定（ProjectSettings/、チーム共有）に分離。旧設定は自動で移行
設定: 「n 件以下は確認を省略」を追加
修正: 設定ウィンドウが開けなくなることがある問題
修正: 右クリックで削除しても一覧が更新されない問題
PBRemap: 名前の対応ルールの正規表現エラーを行内に表示

[3.0.0-beta.6]2026.07.17
PBRemap: アバターの検出を改善（手動指定を最優先、Prefab 境界を優先、ModularAvatar の検出範囲を拡大）
PBRemap: Inspector に検出方法を表示
修正: 検索範囲が「すべて」のとき AvatarDynamics 内のコンポーネントが二重に表示される問題
修正: 空になったフォルダの削除が一部のタブで実行されなかった問題
