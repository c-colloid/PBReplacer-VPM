[3.0.0]2026.09.09
別のアバターや衣装へ PhysBone 等を移植する「PBRemap」を追加
 - AvatarDynamics を別のアバター / MA 衣装 / Animator / 小物へドラッグ＆ドロップすると、ボーン構成の違いを吸収して移植
 - 移植元の参照情報を自動で保存。Prefab 化や別シーン / 別プロジェクトへ持ち出した後も移植できます
 - 着せ替え済みアバター（本体 + MA 衣装）に対応。衣装だけの移植（衣装 v1 → v2、別アバターに着せた同じ衣装）はアバター本体に触れずに行えます
 - 対応するボーンが無いときはヘルパーオブジェクトを自動作成。同名の骨が複数あるときは候補から選択
 - Inspector に「移植元 → 移植先」の流れと ✔ / ＋ / ▾ / ✖ の件数チップ、問題のある行だけの対応表を表示
 - SceneView に対応線を表示。赤 ✕ をクリックすると「ボーン対応」ツールで移植先の骨を選べます。Hierarchy には状態アイコンを表示
 - スケール補正（自動 / 手動 / なし）とドロップ時の動作（自動で移植 / 確認 / ビルド時のみ）を設定できます
 - 「ビルド時のみ」は NDMF 導入時にビルド時へ非破壊で移植（単体の衣装 / 小物は再生開始時）
 - 名前の対応ルール（正規表現）で命名規則の違いを吸収
メインウィンドウの画面を刷新
 - 上部に「アバター → AvatarDynamics」の流れを表示し、真ん中の「再配置 n」ボタンで実行（n は未処理の件数）
 - 左のアイコンから種類（PhysBone / Collider / Constraint / Contact）ごとの表示を切り替え。数字は未処理の件数
 - 一覧は種類ごとの列。○ 未処理 / ✔ 配置済み。行にマウスを乗せると「Hierarchy で表示」「削除」ボタンを表示
 - 複数の種類をまとめて再配置し、1 回の Ctrl+Z か ↶ で戻せます
 - Hierarchy のオブジェクトを列へドロップするとコンポーネントを追加
 - 設定ウィンドウを廃止し、⚙ でウィンドウ内に表示。変更はその場で保存
 - 右上の ⋮ メニューと GameObject メニューから PBRemap を追加できます
ライトテーマに対応
日本語表示に UITK Font Fix を使用（VCC で一緒にインストールされます。日本語 / 中国語 / 韓国語の OS では OS のフォントで表示）
設定: 保存先を個人設定（EditorPrefs）とプロジェクト設定（ProjectSettings/、チーム共有）に分離。旧設定は自動で移行
設定: 再配置 / 移植の前の確認ダイアログを既定でオフに変更（⚙ で有効にできます。「n 件以下は確認を省略」も追加）
修正: 検索範囲が「すべて」のとき AvatarDynamics 内のコンポーネントが二重に表示される問題
修正: 空になったフォルダの削除が一部で実行されなかった問題
修正: 右クリックで削除しても一覧が更新されない問題
修正: 「前回のアバターを自動で読み込む」をオフにしても、開き直すと前のアバターが表示される問題
配布物: リリースの zip / unitypackage から開発用ドキュメント（Docs~）を除外。使い方は README と GitHub の Docs~ を参照
